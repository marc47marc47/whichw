## linux like which 
can compile in windows, linux and macos
usage like linux which command

```bash
  whichw ls
  whichw openssl
  whichw openssl.exe
  whichw code.exe
```


whichw - locate a command in PATH (a cross-platform `which`).
Prints the full path of each command found; works on Windows, Linux and macOS.

Usage: whichw [options] command...

       whichw ls
       whichw openssl
       whichw opewnssl.exe
       whichw code.exe

Options:

  -h, --help    Display this help message
